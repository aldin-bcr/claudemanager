    Nouvelle session
    
      
    
        
        
      
    
      
      
      
      
        
        
      
      
      
      
    Aucune fenêtre ne s'ouvre : la session tourne en arrière-plan avec les permissions de l'équipe (réglables avec ⚙ sur la carte du manager). Tu lui écris depuis l'application. Un worker ne peut écrire qu'au manager.
    
      
    
      
    
        
        
      
    
    
    
      

  
    
    
      
    Ajouter à l'équipe
    
      
      
      
    
      
    
      
    
        
        
      
    
    
    
      

  
    
    
      
    Autorisations des agents
    
      
    Un agent qui se voit refuser une action ou qui demande une autorisation apparaît ici et sur sa session. Tu décides ; le manager ne peut accorder que ce que tu as activé dans les réglages (⚙).
    
      
    En attente
    
      
    Autorisations accordées (révocables en un clic)
    
      
    Journal
    
      
    
    
    
      

  
    
    
      
    Planificateur du manager
    
      
    Toutes les N minutes, l'appli envoie le texte ci-dessous au manager (par la file d'attente : jamais pendant qu'il travaille, jamais deux en attente). Un tick est sauté si rien n'a changé et qu'aucun agent n'est au repos.
    
      
      
    
        
        
      
    
      
      
      
    
      
    
      
    Journal des ticks
    
      
    
    
    
      

  
    
    
      
    Cet agent travaille
    
      
    Le changement demande de redémarrer l'agent (même conversation). S'il est en plein travail, ce travail serait interrompu.
    
      
    
    
    
      

  
    
    
      
    Règles 
    
      
    SI un agent… ALORS l'application agit, sans passer par le contexte du manager (qui reçoit une copie et peut tout arrêter). Chaque règle a un maximum de déclenchements.
